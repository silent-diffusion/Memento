Design review: library screen

Meeting minutes · Monday 5 October 2026, 4:00 PM · 1 h 10 min · Zoom

Executive summary

The team approved the library layout for build with two changes: rows stay at 68 px with status pills shown only for stages that have run, and the processing card hides whenever a filter or search is active.18:42 The dark theme will ship with the first version rather than following later.41:10 The empty state needs copy; Sam owns it.

Meeting purpose

Participants

Discussion summary

Sam opened with the 1440 px mockups and asked whether the row height felt tight.18:10 Priya agreed that a pill on every row made the list busy. The proposal to show pills only for completed or running stages, and a quiet caption for audio-only recordings, was accepted without objection.19:05 On the dark theme, Lee argued that Windows users switch themes with the system and a light-only first release would look unfinished; nobody disagreed.41:10

Decisions

  • Row height stays at 68 px.18:42
  • Status pills only for stages that have run; audio-only shows a caption.18:42
  • Processing card hides while a filter or search is active.19:31
  • Dark theme ships in v1.41:10
